# 마리의 여가 사진첩 / 002권 콘텐츠 관리

001의 [항해 기록 작성 가이드](../voyage-001/AUTHORING.md)를 유지하며 002권과 별도 사진첩을 추가했습니다.
기존 마리의 일기 10편과 VOYAGE 001의 12편/16장은 이 콘텐츠와 합치거나 시간순으로 섞지 않습니다.

## 제공 자료와 역할

- `assets/marie-leisure/*.webp`: 독립 사진 5장, 1448×1086의 4:3 원본 구도.
- `assets/voyage-002/*.webp`: 같은 사진을 자르지 않고 흐린 여백으로 16:9에 담은 5개 프레임 + 1600×900 커버.
- `data/voyage-002/entries.json`: 사건 순서의 5편. `V002-01`~`V002-05`.
- `data/voyage-002/CANON_MEMORY.md`: 002권의 작가 메모. 기존 `data/CANON_MEMORY.md`를 덮어쓰지 않습니다.
- `data/marie_leisure_gallery.json`: 사진별 제목/활동/장소/날짜/시각/설명/alt/원본/일지용 이미지.
- `data/assets_manifest.json`: 제공된 11개 WebP의 크기/용량/SHA-256. 새 그림을 생성하거나 파일을 다시 인코딩하지 않았습니다.
- ZIP의 `registry_entry.json`은 레지스트리 배열에 한 번 추가한 병합용 객체이며, 레지스트리 전체를 교체하는 파일이 아닙니다.

## 사진과 기록의 연결

사진첩의 카탈로그 순서와 일지의 사건 순서는 다릅니다.

| 사진 ID | 원본 | 관련 기록 |
| --- | --- | --- |
| MARIE-LEISURE-01 | 정원 | V002-01 |
| MARIE-LEISURE-02 | 고양이와 독서 | V002-03 |
| MARIE-LEISURE-03 | 일지 작성 | V002-05 |
| MARIE-LEISURE-04 | 드론 정비 | V002-04 |
| MARIE-LEISURE-05 | 티타임 | V002-02 |

연결은 사진의 `diary_image`와 일지의 `image` 경로로 찾습니다. 배열 번호로 연결하지 않습니다.
사진/일지의 day, time, approximate 플래그도 같아야 하며 `validateLeisureGallery()`가 검사합니다.
사진 ID와 원본/프레임 경로가 중복되거나 일지가 없으면 오류로 처리합니다.
현재 앨범은 5장을 대상으로 하므로 콘텐츠를 늘릴 경우 개수 검증과 테스트·표시 문구도 함께 갱신합니다.

원본 사진은 4:3 전체를 표시합니다. 카드/일지에는 제공된 16:9 프레임을 사용합니다.
공유 `figure()`는 `imageDimensions()`의 원본 크기로 placeholder와 표시 비율을 맞춥니다.
확대 창은 화면 높이에 맞추되 `object-fit: contain`과 원본 비율을 유지합니다. 원본 WebP 다운로드는 1448×1086 파일 그대로입니다.

## 설정과 시간

002권에는 DAY 001 파종을 돌아보는 기록과 DAY 002 여가가 함께 있습니다. 07:50/08:15/08:50/09:30은 `대략`으로 표시합니다.
002의 거리 2,037,120 km / 가정 속도 12 km/s / 약 47시간 9분은 **DAY 001 14:58 마지막 관측**입니다.
DAY 002 실시간 값으로 표시하거나 실제 시뮬레이션 시간/자원/비행 모델에 반영하지 않습니다.
001의 정전 스냅샷은 그대로이며 각 권을 선택할 때 그 권의 고정 메모를 보여줍니다.

새로 심은 토마토 씨앗 6개는 발아 대기 중입니다. 사진 속 익은 열매는 기존 재배 구역입니다.
A/B 각 3개, 14h/16h LED 비교만으로 광량·발아·수확 성과를 확정하지 않습니다.
고양이의 이름/종/성별, 드론의 완전 수리/출격, 아공간/스쿨드의 추가 설정은 새로 만들지 않습니다.
인물의 비밀은 일기의 괄호 속 내면/스포일러 안내가 있는 작가 메모에만 둡니다. 사진 카드/alt/공개 소개에는 옮기지 않습니다.

## 정적 게시와 검증

새 파일을 SW 프리캐시에 넣고 VERSION을 올립니다. 전체 파일이 준비되어야 새 worker 설치가 성공합니다.
`pwa.js`의 동의 기반 업데이트는 유지하며 첫 온라인 준비 이후에 오프라인을 지원합니다.
정전 복사/다운로드는 사람이 다음 대화에 직접 전달하는 기능입니다. 자동 대화 수집/ChatGPT 메모리 동기화는 없습니다.

`npm test`, `node tests/leisure.test.mjs`, `python tests/leisure-browser-qa.py`를 실행하고 기존 voyage/room/flight 회귀를 확인합니다.
사진 크기·비율·해시, 일지 전체 본문, 다섯 양방향 링크, 키보드/터치/테마/오프라인/업데이트를 확인합니다.
실기기와 브라우저 에뮬레이션을 구분하고 새 브랜치/OPEN PR로 검토합니다. main 직접 push·병합·배포를 자동 수행하지 않습니다.
